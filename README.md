# Natural Language Processing (NLP)

A practical repository documenting my journey of learning Natural Language Processing with Python, starting from the fundamentals and working toward advanced NLP techniques.

I'm using this repository to keep my code, experiments, notes, and projects organized as I learn how computers work with human language.

## What I'm learning

### 01. NLP Fundamentals
- Introduction to Natural Language Processing
- How computers process human language
- Applications and challenges of NLP
- NLP and its relationship with Machine Learning

### 02. Text Preprocessing
- Regular Expressions (Regex)
- Pattern matching and information extraction
- Text cleaning
- Removing punctuation and special characters
- Lowercasing
- Tokenization
- Stopwords removal
- Stemming and Lemmatization

### 03. Text Representation
- Bag of Words
- CountVectorizer
- N-grams
- TF-IDF
- Word embeddings
- Word2Vec
- CBOW and Skip-gram
- GloVe

### 04. Machine Learning with NLP
- Text classification
- Naive Bayes
- Logistic Regression
- Support Vector Machines
- Spam detection
- Sentiment analysis
- Model evaluation

### 05. Advanced NLP
- Part-of-Speech Tagging
- Named Entity Recognition
- Text similarity
- Topic modeling
- Text summarization

### 06. Deep Learning for NLP
- Neural networks for text
- RNN
- LSTM
- GRU
- Sequence-to-sequence models
- Attention mechanism

### 07. Transformers and LLMs
- Transformer architecture
- Self-attention
- Positional encoding
- BERT
- GPT
- Tokenization
- Fine-tuning language models
- Hugging Face Transformers
